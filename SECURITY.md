# Security

Jali is a research implementation. It has not been audited, and it makes no constant-time
guarantee. Do not use it to protect real data without an independent review. The [security
notes](docs/security.md) describe what the proofs do and do not guarantee.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: on the repository's **Security** tab,
choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

Only the latest release, and the `main` branch, receive fixes.
